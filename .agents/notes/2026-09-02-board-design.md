# Kanban visual hierarchy

The interface prioritizes task supervision: status filters focus one column, secondary settings use a native disclosure, and bounded agent trees keep long hierarchies from stretching the board. Child metadata remains accessible through Model & usage disclosures. State dots accompany written status labels; unavailable cost is removed from the summary strip.

The design retains Harness semantic colors and system typography so light and dark themes remain consistent with the host. Task titles use 14/20 type, utility data uses 11/16 with tabular totals, and layout spacing follows a 4px scale. The characteristic element is the agent hierarchy within a task, with bounded scrolling and state labels.

The original wide filter row and equal-weight buttons made every control compete with the task. The revised layout gives task counts greater weight than informational metrics and leaves advanced settings collapsed. Focused status views provide readable width for nested agents. Native disclosures, focus outlines, and reduced-motion behavior preserve keyboard accessibility.
